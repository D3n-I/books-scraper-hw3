# Books Scraper

Учебный проект по сбору данных с https://books.toscrape.com/.

Парсер получает название, цену, рейтинг, остаток, описание и все поля
таблицы Product Information. Результат сохраняется в текстовом формате
JSON. Пример полного набора данных находится в `artifacts/books_data.txt`.

## Установка

Требуется Python 3.11 или новее. Команды выполняются из корня проекта.

```powershell
conda create -n temp_hw python=3.11 pip
conda activate temp_hw
python -m pip install -r requirements.txt
```

Если окружение `temp_hw` уже создано, достаточно активировать его
и установить зависимости.

## Сбор данных

```powershell
python scraper.py
```

После успешного обхода всех страниц файл `books_data.txt` создаётся
или обновляется в текущей рабочей папке.

```python
from scraper import get_book_data, scrape_books

books = scrape_books(is_save=False)
```

`is_save=False` возвращает данные без записи файла. Для запросов
используются тайм-аут и общая HTTP-сессия; при временных сетевых
ошибках выполняются повторные попытки.

## Ежедневный запуск

```powershell
python scraper.py --schedule
```

Сбор выполняется ежедневно в 19:00 по локальному времени компьютера.
Процесс должен оставаться запущенным, а компьютер — включённым
и не находиться в режиме сна. Для остановки нажмите Ctrl+C.

## Ноутбук

Файл: `notebooks/Миронов_Данила_Геннадьевич_HW_03_python_ds.ipynb`.

Откройте его в VS Code и выберите ядро `temp_hw`. В файле сохранены
результаты выполнения ячеек. Начальная ячейка настройки определяет
корень проекта, поэтому пути к тестам и данным работают при открытии
ноутбука из папки `notebooks`.

Проверка расписания назначает полный сбор на следующую минуту
в формате ЧЧ:ММ и завершается после одной выгрузки. Параметр
`once=True` используется только для этой проверки. В обычном режиме
`run_schedule()` продолжает работать ежедневно в 19:00.

Повторный запуск всех ячеек выполняет два полных сбора каталога:
обычный и по расписанию. Это занимает несколько минут.

## Тесты

```powershell
pytest -v
```

Три теста проверяют данные одной книги, переход между страницами,
сохранение результата и отсутствие записи при `is_save=False`.
Используются подготовленные HTML-страницы и временная папка pytest.
Запросы к реальному сайту при выполнении тестов не отправляются.

## Файлы

- `scraper.py` — парсер и запуск по расписанию.
- `tests/test_scraper.py` — автотесты.
- `pytest.ini` — настройки pytest.
- `requirements.txt` — версии зависимостей окружения.
- `artifacts/books_data.txt` — данные о книгах.
- `notebooks/Миронов_Данила_Геннадьевич_HW_03_python_ds.ipynb` — ноутбук.
- `.gitignore` — исключения Git.

Основные библиотеки: requests, beautifulsoup4, schedule, pytest, ipykernel.
